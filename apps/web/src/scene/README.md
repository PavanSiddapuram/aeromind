# Three.js Scene

The scene is a deterministic visual fixture for the AeroMind simulation.

## Coordinate convention

- X: east/west
- Y: altitude (up)
- Z: north/south
- World units: synthetic metres

The drone's visual reference point is the centre of its body. Building meshes are centred at half their height, while collision bounds should be stored separately in world coordinates and converted into the same convention.

## Current scene contents

- One synthetic flood-water ground plane and visual current lines.
- Procedurally placed low-poly building boxes.
- Rooftop rescue target markers.
- One quadcopter-style visual model with four animated rotor blades.
- A home/launch pad.
- A dashed illustrative route.
- Orbit controls for camera inspection.

## Important implementation boundary

The route and telemetry in the first scene are illustrative display data. They are not yet generated by A*, verified by the geometry engine or consumed by a mission executor. Keep the visual scene separate from the canonical environment/collision model. In the next integration step, both rendering and collision calculations must be generated from the same scenario data source.
